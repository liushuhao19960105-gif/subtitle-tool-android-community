# V1.8.5 · 中文字幕可读性与质量初检（分阶段开发）

状态：**独立开发分支，尚未合并、未发布 APK**。此版本建立在 V1.8.4 的断点恢复及界面优化基础上。

## 已完成的技术改进
- ASS 输出只在**显示层**选择更合理的双行换行位置，优先中文标点和自然语义停顿，避免将同一个英文单词切断，保留每条中文原文和时间码。
- 本地离线质量检查：检查漏译、无效时间码、纯标点、阅读速度过高、译文过长、疑似孤立助词、可疑相邻重复。
- 保留成人语境中的真实短促发声，不因重复“啊”等自动删改；质量建议**不会自动覆盖译文**。
- 任务完成后在手机端提供「查看字幕质量报告」，只包含字幕编号和待复核原因，报告保存在 App 私有目录，不调用第三方 API，不记录 API Key。
- 新增可执行的 Java 回归测试，以验证换行不会丢字、时间码未受修改，以及常见诊断的安全性。

## 待完成的验收工作
- 在真机使用几段不同长度的视频确认字幕不遮挡视频画面，中文不被不合理断开；
- 针对影视对白、多人对话和语气词补充更多质量测试样例；
- 未来 V1.9.0 增加逐条字幕预览及编辑，允许用户对报告中提示的问题逐条调整；
- 进一步加入更准确的中文语义断句（考虑语义模型费用与逐句上下文），在充分回归测试前不自动重写台词。

## 双仓库
公共与私有仓库各自保持独立的功能分支，功能代码与测试同步；签名/Secrets 仅保留在私有仓库。V1.8.5 不会自动合并 V1.8.4 或触发正式发布。
