# V1.9.0 字幕列表与逐句编辑

状态：**开发分支 / 草稿 PR；私有仓库已有同签名测试 APK，尚未正式发布**。本阶段建立在 V1.8.5 的离线质量报告之上。

## 已实现
- 完成字幕制作后，主界面显示「字幕预览与编辑」按钮。仅展示最近一次成功生成并保存了可编辑字幕的数据。
- 点击进入本机字幕列表，显示字幕编号、英文原文、中文译文与起止时间；点击某条字幕可直接编辑其中文。
- 编辑不改变英文识别文本、说话人、时间轴和字幕 ID；输入不能为空且最多 250 字。
- 编辑后在 App 私有目录保存新的字幕草稿，重新生成同一份 `last_result.ass`，之后可用原有「下载中文字幕 ASS」按钮导出。
- 同步重新计算本地字幕质量报告，不发起新的 AI 或语音识别 API 请求，也不要求额外 Android 权限。
- 编辑页不可被外部 App 直接启动（AndroidManifest `exported=false`）；字幕草稿留在 App 私有目录，未存入开源仓库。

## 使用限制
- **明确不开发视频画面叠加字幕的实时预览功能**。根据产品负责人的决定，该功能已从后续开发计划中移除；仅保留便于查错和修改的字幕文字列表。
- 旧版 V1.8.4 仅保存 ASS、不保存逐条完整译文，因此**需要使用 V1.9.0 生成一次字幕**，才会出现可编辑列表。升级安装后已有 ASS 仍可直接下载。
- 当前只保留最新一次生成的字幕草稿，并允许逐条编辑。尚无批量替换、撤销历史、复杂时间轴拖拽或多项目管理。
- 所有编辑只在本机完成。卸载或清除应用数据会移除私有草稿和已保存的密钥。
- 编辑数据与 ASS 为两个本机文件，保存失败时尝试回滚；仍需真机测试异常关闭、不同机型、超长字幕与多说话人场景。

## 双仓库与正式版
社区仓库提供不含签名密钥的源码与测试；私有仓库保留固定签名流程。此分支以 V1.8.5 分支为基线，两边同步实现，但 **V1.9.0 不是正式发布版本**；V1.8.4 现有安装包不受影响。
