# V1.9.1：英语俚语与成人对白翻译优化、API 用量和质量模式

状态：独立功能分支、仅供测试。依赖 V1.8.5 中文断句和质量检查，以及 V1.9.0 字幕文字列表与逐句编辑。

## 用户只批准开发以下内容
1. **V1.8.5 中文断句和排版**：保证英文原文/中文字幕不被自动删除、时间轴不变；较长中文可按标点及自然断点换行，对阅读速度过高的字幕报警。
2. **V1.8.5 字幕质量检测**：增加漏译、疑似否定/数字错译线索、异常重复、孤立助词和语气词保护。所有结果只是建议，不自动改写台词。
3. **V1.9.0 字幕文字列表与逐句编辑**：查看英文、中文和时间码；修订中文后更新本地 ASS。**不开发视频播放或画面字幕实时预览。**
4. **英语俚语与成人对白翻译优化**：根据上下文识别常见多义词、脏话、双关、成人场景和明确识别的喘息/呻吟；保持原意及粗俗程度，不凭猜测添色情内容。测试案例为虚构、公开安全的纯文字数据。
5. **API 费用统计和质量模式**：快速 1 轮、标准 3 轮、高质量 4 轮；高质量模式在三轮之后增加跨批次核对。每次模型响应若包含 `usage.prompt_tokens` 和 `usage.completion_tokens`，把真实返回数记入本机私有文件。

## 费用数据说明（重点）
- **实际 Token 数 ≠ 实际账单**。只统计翻译聊天 API 明确上报的输入/输出 Token；没有 usage 时标记未知，不虚构数值。
- 费用按**用户手动输入的每百万输入/输出 Token 美元单价**计算，属于估算；默认不设置单价。多轮、长视频、高质量模式会增加请求量和可能的费用。
- 不含 Deepgram/AssemblyAI 的语音识别费用；这些通常按时长计费，不能从翻译 Token 推导。
- 请求已经送出但网络在返回前失败，计费状态可能未知；不能保证重复计费为零。
- 本机每个最近任务只有一份累计翻译 Token 统计；相同视频和模型继续任务时重用。不同视频或配置不复用；不会保存密钥、API 原文、视频或译文到用量文件。
- V1.8.4 既有标准模式断点指纹沿用，快速/高质量使用不同指纹避免复用错误的批次；高质量第 4 轮具有独立恢复计数。

## 限制与发布流程
- 所有模型翻译质量仍需用实际 API 及真实素材真机验收。纯文本测试只保证代码结构、歧义覆盖与处理安全，不能保证任意模型一定翻译正确。
- V1.8.5 / V1.9.0 / V1.9.1 在公开和私有仓库分别保留独立草稿 PR，双仓库同步功能代码，公共仓库不放任何正式签名密钥。
- 用户未勾选的背景通知、多任务历史、额外特性以及视频实时预览均不开发。
- **正式合并和正式发布由用户确认**；测试版同签名 APK 只能用于用户自行安装验收。
