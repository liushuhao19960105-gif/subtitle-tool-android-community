# 英文俚语与成人对白专用词库（V1.9.1 增补）

状态：独立 **草稿开发分支**，用户此前明确勾选的「英文俚语与成人对白翻译优化」的补全工作。

## 词库实际位置和规模
- `app/src/main/assets/dialogue_lexicon_v191.tsv`：**110 条人工整理的多义词/常用语/声音事件提示**。
- 每行 6 列：编号、英文短语、类别、适用语境、候选中文解释、不得误判的内容。
- 类别包含粗口、俚语、多义、日常对白、成人俚语、语气词、声音事件、专名等。
- `DialogueLexicon.java`：负责读取、验证并选择本批字幕相关词条。词库保存在 APK 内，**不是人工在每次翻译时复制粘贴**。

## 运行时的实际用法
1. 翻译任务开始时从 APK 内读取 TSV，严格校验字段、条目数和编号。若加载异常则反馈错误，避免用户误以为词库已生效。
2. 逐批查看目标英文字幕，仅命中相关英文短语；使用完整英文词/词组边界匹配（`come` 不匹配 `become`）。
3. 较长的具体词组优先，每批最多 **10 条**、不超过约 **1800 个提示字符**，以防无关词条挤占模型上下文并产生额外 Token 费用。
4. 将候选解释、适用语境和常见误译放到 `dialogue_lexicon_hints` 字段，供 **初译、润色、全片审查及高质量第四轮复核**参考。
5. **不自动替换中文字幕**，不能单凭英文词条就推断有成人动作；仍由同一翻译模型结合前后文决定。英文字母短语只能作为词库提示，不是硬性翻译指令。
6. 不改变原字幕 ID、英文、说话者、原时间轴或 ASS 样式。连续短促发声不因重复就被丢弃。

## 如何继续扩充
- 直接新增 TSV 行，可在社区仓库通过 PR 审核，需提供英文短语、上下文、候选译法以及易误译原因。
- 优先新增成对歧义案例，如 `come here` / `coming`、`get off the bus` / `get off on`、`screw up` / `screw`。
- 禁止将私人视频、原始字幕、手机号、API Key、真实人物的私密内容等提交进公开库。
- 新词条需要经过 TSV 格式、JVM 匹配和 Android 自动编译测试。
- 当前尚无内置用户词库编辑器、在线词库服务或自动联网下载，避免未经用户批准拓展功能范围。

## 验收及限制
- 现有 **22 条上下文翻译测试样例**用于覆盖典型歧义；新增的 110 条是词库条目数，二者不是同一数量。
- Java 回归测试验证解析、匹配边界、常见短语与缺失数据行为，但不能保证服务商模型在所有素材中都选对词义；真实素材需要用户实测。
- 词库条目是随 APK 发布的静态版本，未来更新必须走双仓库同步、草稿 PR、安全审核和用户确认的流程。
- **尚未正式合并发布**，此前已经给出的 V1.9.1 版本号 18 安装包不包含本新增词库。当前增补使用版本号 19，需生成新的私有同签名测试 APK 后才能测试。
