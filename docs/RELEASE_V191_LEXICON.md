# V1.9.1 对白词库增强版（社区源码发布）
版本标识：v1.9.1-lexicon；社区版本号 versionCode 19。
这是与私有原签名正式版核心功能同步的开源源码版本。

## 更新
- V1.8.4：翻译批次断点恢复、限次 HTTP 429 重试和更清晰的手机界面
- V1.8.5：中文 ASS 换行、阅读速度及漏译/异常重复/否定数字线索报告
- V1.9.0：本机中文字幕文字列表、逐句编辑和 ASS 重新导出（无视频画面预览）
- V1.9.1：快速 1 轮、标准 3 轮、高质量 4 轮；翻译 API 返回 Token 用量统计与按用户输入单价的估算费用
- 英文俚语/成人对白翻译增强：110 条可维护上下文词库条目、22 条基础歧义测试案例、首译/润色/全片复核和第 4 轮词库辅助

## 安全与下载
此仓库只发布**不含正式签名私钥和任何 Secrets 的源码**。社区 Debug APK 使用不同签名，不能覆盖安装私有正式版。
原签名 APK 仅通过维护者的私有正式仓库提供，必须由有权限的人访问。
软件会根据用户设置将音频/字幕文字发送到选定的 API，第三方可能产生费用。
Token 数量仅对已返回 usage 的翻译调用准确，估算费用不等于平台账单，且不包含语音识别费用。

## 版本验证
社区 CI 包含离线回归、真实 Java 词库边界测试、Android SDK 35 编译和 APK 签名完整性校验。
本版本需要用户实际场景继续验收翻译语义效果；不会为了词库自动改写或删除识别的原对白。
